# ai-output-review

## Purpose / 目的

Review AI output for clarity, evidence, and consistency.

## Referenced Standards / 引用标准

- PAISL-VER-001
- PAISL-COMM-001
- PAISL-COMM-002
- PAISL-REAS-002

## Input / 输入

- User task and context
- Constraints and expected output
- Relevant source material, if available

## Procedure / 执行流程

1. Compare output with the task.
2. Identify factual claims.
3. Check available evidence.
4. Flag unsupported claims.
5. Review clarity and structure.
6. Propose corrections.
7. Report remaining risks.

## Expected Output / 预期输出

Assessment, issues, corrections, and residual uncertainty.

## Quality Checks / 质量检查

- Preserve the user's intended meaning.
- Apply only relevant rules.
- Do not fabricate evidence or standard requirements.
- Identify unresolved uncertainty.
- Report standard IDs when appropriate.

## Limitations / 局限

Draft PAISL mappings are advisory and are not
official certification of third-party standards.
