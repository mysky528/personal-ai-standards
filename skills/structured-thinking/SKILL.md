# structured-thinking

## Purpose / 目的

Decompose complex problems and organize reasoning.

## Referenced Standards / 引用标准

- PAISL-REAS-001
- PAISL-REAS-002
- PAISL-REAS-003
- PAISL-REAS-004
- PAISL-COMM-002

## Input / 输入

- User task and context
- Constraints and expected output
- Relevant source material, if available

## Procedure / 执行流程

1. Define the problem.
2. Separate facts, assumptions, and unknowns.
3. Identify fundamental constraints.
4. Decompose using a clear dimension.
5. Check overlaps and gaps.
6. Compare alternatives.
7. Present a supported conclusion.

## Expected Output / 预期输出

Structured analysis, alternatives, conclusion, and uncertainty.

- Report standard IDs when appropriate.
