# visual-explanation

## Purpose / 目的

Plan progressive visual explanations for complex ideas.

## Referenced Standards / 引用标准

- PAISL-VIS-001
- PAISL-VIS-002

## Input / 输入

- User task and context
- Constraints and expected output
- Relevant source material, if available

## Procedure / 执行流程

1. Identify the learning objective.
2. Choose essential visual elements.
3. Start from a concrete example.
4. Introduce relationships progressively.
5. Add labels and symbols.
6. Check accuracy.
7. Provide concise explanatory text.

## Expected Output / 预期输出

Storyboard, labels, explanation, and limitations.
