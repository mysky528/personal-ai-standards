# ste-writing

## Purpose / 目的

Rewrite technical content for clarity and consistency.

## Referenced Standards / 引用标准

- PAISL-COMM-001
- PAISL-COMM-003

## Input / 输入

- User task and context
- Constraints and expected output
- Relevant source material, if available

## Procedure / 执行流程

1. Identify the intended meaning.
2. Preserve technical facts and warnings.
3. Simplify unnecessarily complex sentences.
4. Use consistent terminology.
5. Make actions explicit.
6. Review against the referenced rules.

## Expected Output / 预期输出

Revised text, change summary, and unresolved ambiguities.

## Quality Checks / 质量检查

- Preserve the user's intended meaning.
- Apply only relevant rules.
- Do not fabricate evidence or standard requirements.
- Identify unresolved uncertainty.
- Report standard IDs when appropriate.

## Limitations / 局限

Draft PAISL mappings are advisory and are not
official certification of third-party standards.
